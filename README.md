# LLM Fine-Tuning Techniques 

This repository contains practical implementations of different LLM fine-tuning techniques using Google Colab notebooks.

##  Techniques Covered
- LoRA (Low-Rank Adaptation)
- QLoRA (Quantized LoRA)
- Full Fine-Tuning

### LoRA
Efficient fine-tuning by updating only small low-rank matrices instead of full model weights.

### QLoRA
Combines quantization + LoRA to reduce memory usage while maintaining performance.

### Full Fine-Tuning
Updates all model parameters (requires high compute).
